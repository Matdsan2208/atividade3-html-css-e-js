# 🐾 Dom’s Pet – HTML5, CSS3 e JavaScript

Projeto desenvolvido na disciplina **Desenvolvimento Front-End para Web (Cruzeiro do Sul Virtual)**  

O **Dom’s Pet** é um site institucional de uma ONG fictícia dedicada ao **resgate, cuidado e adoção responsável de animais**.  
O objetivo do projeto é aplicar os conhecimentos práticos de **HTML, CSS e JavaScript**, abordando estrutura semântica, design responsivo e interatividade com o usuário.

---

## 🐕 Sobre o Projeto

O site foi desenvolvido com foco em **usabilidade, acessibilidade e experiência do usuário**, contendo três páginas principais:
- **Início** – Apresenta quem somos, missão, visão, valores e resgates marcantes.  
- **Projetos** – Mostra as principais iniciativas da ONG, como *Adoção com Amor*, *Pet Resgate* e *Lar Temporário*.  
- **Cadastro** – Permite o registro de voluntários e adotantes com validação de dados e feedback interativo.  

---

## ⚙️ Funcionalidades Implementadas

- 🌙 **Modo Escuro (Dark Mode)** com salvamento da preferência no navegador.  
- 🍔 **Menu Hambúrguer Responsivo** com acessibilidade e fechamento automático.  
- ✅ **Validação de Formulário** com feedback visual e notificações tipo *toast*.  
- 🧩 **Máscaras Automáticas** para CPF, Telefone e CEP.  
- 💬 **Sistema SPA Simples** simulando navegação fluida entre páginas.  
- 🎨 **Design Responsivo** desenvolvido com CSS Grid e Flexbox.  
- ♿ **Acessibilidade** aplicada com atributos ARIA e navegação otimizada.  

---

## 🧠 Tecnologias Utilizadas

- **HTML5** → Estrutura semântica e acessível.  
- **CSS3** → Layout responsivo, variáveis de cor, tipografia e modo escuro.  
- **JavaScript (ES6+)** → Interatividade, validação, dark mode e máscaras dinâmicas.
